记录一些 HTML 学习中的重要知识点和技巧。事实证明几天不用就很容易忘。

## 段落与换行

- 可以用 `<p>` 标签来定义段落。
- 可以用 `<br>` 标签来换行。

## 特殊字符转义

有一些特殊字符需要转义：

| 字符 | 写法 |
| --- | --- |
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |

写 HTML 的时候如果直接把 `<` 敲进正文，浏览器会把它当成标签的开始，所以该转义的地方一定要转义。
